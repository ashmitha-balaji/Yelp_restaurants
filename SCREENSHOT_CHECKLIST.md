# Lab 1 Screenshot Checklist

Use this checklist while capturing screenshots for your report. Ensure both **backend 2** and **frontend 2** are running.

## Screenshots to Capture (in order)

### 1. Home Page with Chatbot
- [ ] Open http://localhost:3000 (logged in)
- [ ] Ensure the red AI chat button is visible (bottom-right)
- [ ] Show restaurant cards and search bar
- [ ] **Save as:** `01_home_chatbot.png`

### 2. Restaurant Search
- [ ] Use search/filters (cuisine, city, keyword)
- [ ] Show results with at least 3–4 restaurant cards
- [ ] **Save as:** `02_restaurant_search.png`

### 3. Restaurant Details
- [ ] Click any restaurant
- [ ] Show full details: name, address, rating, reviews list
- [ ] **Save as:** `03_restaurant_details.png`

### 4. Profile & Preferences
- [ ] Go to Profile
- [ ] Show profile photo (if uploaded) and fields
- [ ] Go to Preferences — show cuisine, price, dietary, ambiance options
- [ ] **Save as:** `04_profile_preferences.png`

### 5. Reviews
- [ ] Option A: Restaurant page with reviews section
- [ ] Option B: Write Review form
- [ ] Option C: My Reviews page
- [ ] **Save as:** `05_reviews.png`

### 6. AI Chatbot Conversation (Required)
- [ ] Click the AI chat button
- [ ] Type: "Find dinner tonight" or "Best rated near me"
- [ ] Wait for AI response with recommendations
- [ ] Show the full conversation including clickable restaurant cards
- [ ] **Save as:** `06_ai_chatbot.png`

### 7. Second AI Example (Optional)
- [ ] Clear chat or start new
- [ ] Ask: "Vegan options" or "Something romantic"
- [ ] **Save as:** `07_ai_chatbot_2.png`

### 8. Owner Dashboard
- [ ] Sign in as Restaurant Owner
- [ ] Go to Owner Dashboard
- [ ] Show analytics / recent reviews
- [ ] **Save as:** `08_owner_dashboard.png`

### 9. Swagger API Test
- [ ] Open http://localhost:8000/docs
- [ ] Expand an endpoint (e.g., GET /restaurants/)
- [ ] Click "Try it out" → "Execute"
- [ ] Capture the response
- [ ] **Save as:** `09_swagger_api.png`

---

## Tips

- Use **full window** or **browser zoom 100%** for consistency
- Hide bookmarks bar if it clutters the view
- For chatbot: capture when recommendations are fully loaded
- Ensure screenshots are clear and readable
