# Project Rules — Strict

## Rule 1: No AI tool attribution
Never mention or attribute the AI assistant (or any AI tool) in:
- Code comments
- Commit messages (no "Co-Authored-By" lines, no AI generation tags)
- Pull request descriptions
- Documentation files
- README sections
- File headers
- Reports
- Anywhere else, period.

This is a hard rule with no exceptions.

## Rule 2: Show terminal work transparently
When running terminal commands on the user's behalf, always present:
- The exact command(s) executed
- The exact output received
- In a clean, copy-pastable / screenshot-friendly format

This supports the user's need to document their work for reports.
